# PrepHub 🚀

PrepHub is a comprehensive, AI-powered platform built on the **MERN stack** (MongoDB, Express, React, Node.js) to help students and professionals prepare for technical interviews, build their resumes, network with peers, and apply for jobs all in one place.

## ✨ Key Features

### 🧠 AI-Powered Coding Practice
- **Real-time Evaluation**: Write code in our integrated editor and get immediate feedback powered by the **Google Gemini AI API**.
- **Smart Analytics**: AI checks for syntax errors, logical bugs, and suggests time/space complexity optimizations.
- **Ideal Solutions**: Get an optimal solution generated by AI if you get stuck.

### 👔 Interactive Interview Prep
- **Dynamic Questions**: AI generates technical interview questions based on your target role and difficulty level.
- **Answer Evaluation**: Submit your answers and receive constructive feedback and the ideal response from our AI interviewer.

### 📄 Resume Builder
- **Dynamic Templates**: Create professional, ATS-friendly resumes.
- **Real-time Preview**: See your resume take shape as you type.
- **Easy Export**: Download or save your resumes for job applications.

### 🏢 Job Portal & ATS
- **Job Listings**: View open positions posted by admins/recruiters.
- **One-Click Apply**: Submit your profile and generated resume directly to jobs.
- **Application Tracking**: Track your application status (Pending, Accepted, Rejected).
- **Admin Dashboard**: Recruiters can review applicants, view CVs, and update statuses.

### 🌐 ConnectHub (Networking)
- **Social Feed**: Share updates, articles, and achievements.
- **Engagement**: Like and comment on posts from other users.
- **Community**: Connect with peers, view profiles, and expand your professional network.

### 🔐 User Management & Security
- **Authentication**: Secure login and signup flows.
- **Role-based Access**: Differentiates between standard 'Developers' and 'Admins/Recruiters'.
- **Profile Customization**: Manage your bio, education, and professional roles.

## 🛠️ Technology Stack

- **Frontend**: React.js, Vite, Tailwind/Custom CSS
- **Backend**: Node.js, Express.js
- **Database**: MongoDB & Mongoose
- **AI Integration**: Google Gemini API (`@google/generative-ai`)
- **File Handling**: Multer (for CV & Resume uploads)

## 🚀 Installation & Setup

### Prerequisites
- Node.js (v16 or higher)
- MongoDB (Running locally or via MongoDB Atlas)
- Google Gemini API Key

### 1. Clone the Repository
```bash
git clone https://github.com/Priyanshukumar23/PrepHub.git
cd PrepHub
```

### 2. Install Dependencies
You need to install dependencies for both the backend and the frontend.

**Backend:**
```bash
npm install
```

**Frontend:**
```bash
cd client
npm install
cd ..
```

### 3. Environment Variables
Create a `.env` file in the root directory and add your API keys:
```env
# Root Directory .env
GEMINI_API_KEY=your_gemini_api_key_here
PORT=3000
```
*(Note: Your local MongoDB connects automatically via `server.js` to `mongodb://127.0.0.1:27017/prephub`. If using Atlas, you will need to update the Mongoose connection string in `server.js`)*

### 4. Start the Application

You will need two terminals to run the full stack locally.

**Terminal 1 (Backend Server):**
```bash
# In the root PrepHub directory
node server.js
```

**Terminal 2 (React Frontend):**
```bash
# In the PrepHub/client directory
cd client
npm run dev
```

The frontend will start on `http://localhost:5173` and the backend will run on `http://localhost:3000`.
